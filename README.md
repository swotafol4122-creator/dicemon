# ころがれ！ダイスモン

サイコロで たたかい、あつめて、まぜて、そだてる。
すごろく × モンスター収集RPG です。ブラウザだけで動きます（インストール不要・オフライン対応）。

## どんなゲーム？

- **サイコロバトル**：なかま1体につき6面のサイコロが1つ。こうげき・まもる・かいふく・わざ・ラッキー★・からっぽ の面があります。1ターン2回まで振りなおせて、同じマークをそろえると **役**（ペア／トリプル／ゾロ目／かいだん／いろそろい）が成立してパワーアップ。敵が次にする行動は先に見えるので、それを読んでサイコロを組み立てます。
- **すごろく探索**：8つの町エリアをサイコロで進みます。くさむら・宝箱・ハプニング・おみせ・しょうぶ・ゴールのヌシ。サイコロを振るたびに時間が進み、夜にしか出ないダイスモンもいます。
- **73体のダイスモン**：ロウソク、でんち、くつした、ふうりん など身近なモノが主役。6属性（ほのお→しぜん→でんき→みず→ほのお、ひかり⇄やみ）。
- **スカウト**：弱らせて、ダイスを投げて、出た目で仲間に。好きなおやつをあげる・眠らせると成功しやすくなります。
- **まぜまぜ（配合）**：Lv10以上の2体から新しい子が生まれます。親のサイコロの面を選んで受けつげるのが最大の特徴。+値、特別レシピ25種（図鑑にヒント）。
- **やりこみ**：しんか、面をみがく、色ちがい、ムゲンのとう、クリア後の「ほしのうら」と伝説6体、称号28種、オートバトル。
- **ともだち**：チームコードで友だちのチームと対戦、こうかんコードで仲間を送れます。

## GitHub Pages で公開する

1. GitHub で**このゲーム専用の新しいリポジトリ**を作る（Public）。ほかのゲームと同じリポジトリ（同じURL）に入れると、スマホが同じアプリだと思ってしまうので分けてください。
2. このフォルダの中身をすべてアップロード（「Add file」→「Upload files」）。
   - `index.html` `manifest.webmanifest` `sw.js` `icon-192.png` `icon-512.png` `icon-maskable-512.png` `README.md`
3. リポジトリの **Settings → Pages** を開き、「Build and deployment」の **Source** で **Deploy from a branch** を選ぶ。
4. ブランチに **main**、フォルダに **/(root)** を選んで **Save**。
5. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で遊べます。

`index.html` だけをパソコンで開いても遊べます（その場合アプリ化・オフライン機能は使えません）。

## スマホのアプリにする

- **iPhone**：Safari で開く →「共有」→「ホーム画面に追加」
- **Android**：Chrome で開く →「︙」→「アプリをインストール」（または「ホーム画面に追加」）

一度開けばオフラインでも遊べます。

### 「すでにインストールされています」と出るとき

- **もう入っています。** Android の Chrome は、アプリを「アプリ一覧（ドロワー）」に入れます。ホームの設定で「ホーム画面にアプリアイコンを追加」がオフだと、ホームにアイコンが出ません。アプリ一覧で「ダイスモン」を探して、長押しでホーム画面に置いてください。
- **前にホームのアイコンだけ消した**場合も、アプリ自体は残っています（設定 → アプリ で確認・削除できます）。
- **前に別のゲームを同じURLで入れていた**場合、Chrome はそれと同じアプリだと判断します。ゲームごとにリポジトリを分けてください。

## データについて

- 進行はブラウザに自動保存されます。
- 機種変更やブラウザを変えるときは、**メニュー → せってい → データのひきつぎ** でコードを作り、新しい方で読み込んでください。
- 内容を更新したら、ファイルを上書きアップロードするだけでOK。次に開いたときに新しい版になります。

## 操作のコツ

- バトル：サイコロをタップして選ぶ →「ふりなおす」→「けってい！」。敵をタップでねらう相手を変更、もう一度タップでくわしい情報。
- 右上の「オート」で自動バトル、「×2」でスピード変更。
- 困ったら **メニュー → あそびかた**。
